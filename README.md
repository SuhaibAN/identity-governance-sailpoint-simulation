# Identity Governance SailPoint Simulation

This project simulates Identity Governance and Administration (IGA) workflows commonly used in SailPoint-style identity governance environments.

The goal is to demonstrate practical understanding of identity lifecycle management, access requests, approvals, entitlements, access reviews, certifications, and revocation.

## Scenario

MapleTech Financial is a mock financial services company.

The environment includes users from HR, Finance, IT, and Contractor teams. Access is governed through roles, entitlements, approval workflows, and periodic access reviews.

## Key Concepts Covered

- Joiner, Mover, Leaver lifecycle
- Identity source and user attributes
- Role and entitlement mapping
- Access request workflow
- Manager and application owner approval
- Access review / certification
- Privileged access review
- Contractor access review
- Revocation and remediation
- Least privilege access control

This is a simulation project using documentation and templates to model how IGA workflows work in platforms such as SailPoint IdentityIQ, SailPoint Identity Security Cloud, Entra ID Governance, Saviynt, and Okta Identity Governance.

Built a practical IGA simulation covering identity lifecycle, role-based access, entitlement governance, access requests, approvals, certifications, and revocation workflows.

## Disclaimer

This is a personal simulation project using mock users, mock applications, and mock access data. No real company data, production credentials, or sensitive information are included.
